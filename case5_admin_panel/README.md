# Кейс 5: Telegram-бот заявок с админ-панелью

Бот принимает заявку в свободной форме, определяет услугу и контакт, сохраняет
заявку в JSON и присылает уведомление админу. Веб-панель показывает список
заявок, позволяет менять статус, ищет по тексту и экспортирует в CSV.

Ни одной внешней зависимости - только стандартная библиотека Python 3.9+.
Именно поэтому его можно развернуть где угодно за минуту.

## Что умеет

- Приём заявок текстом, без кнопок и обязательных полей
- Автоопределение услуги: лендинг / телеграм-бот / парсер цен / админ-панель
- Извлечение контакта: @юзерник, телефон, ссылка
- Уведомление админу в Telegram сразу при заявке
- Панель: список, фильтр по статусу, поиск, смена статуса, экспорт CSV
- Статусы заявки: `new` -> `in_progress` -> `done` / `rejected`
- Нормализация украинских букв (і, ї, є, ґ) - заявки на украинском читаются так же

## Запуск панели

```bash
export ADMIN_TOKEN=change-me      # токен доступа к API и CSV
export ADMIN_PORT=8080
export LEADS_FILE=leads.json
python3 panel.py
```

Панель откроется на `http://<host>:8080`. Если `ADMIN_TOKEN` не задан, панель
работает без пароля - удобно для локальной демонстрации, но не для продакшена.

## Подключение бота

```bash
export TG_TOKEN=123:ABC
export ADMIN_CHAT_ID=7409753745
export LEADS_FILE=leads.json
python3 bot.py
```

Бот и панель работают с одним файлом `leads.json` - это их общая точка данных.
Панель можно перезапускать, данные не теряются: запись идёт через временный
файл и атомарную замену.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET  | `/api/leads?token=TOKEN` | список заявок (JSON) |
| POST | `/api/leads` | создать заявку: `name`, `contact`, `service` |
| POST | `/api/leads/{id}/status` | сменить статус |
| GET  | `/export.csv?token=TOKEN` | выгрузка CSV |

Токен передаётся в поле `token` (POST) или заголовке `X-Admin-Token`.

## Почему так

Заказы на бота и лендинги часто приходят в свободной форме: человек пишет
«нужен бот под запись, в телеге @ivan». Жёсткие формы с обязательными полями
теряют такие заявки. Здесь бот делает минимум - достаёт контакт и услугу, а всё
остальное видно в панели, где заявку можно довести до сделки вручную.

Развёртывание: обычный `python3 panel.py` на VPS, systemd-юнит для автоперезапуска,
nginx с сертификатом - и панель доступна клиенту по ссылке.
