# Шаблон лендинга

Одностраничный сайт услуги. Чистый HTML/CSS, без внешних CDN, работает офлайн.

Что настроить под клиента (5 минут):
1. В `index.html` — заголовок, описание услуги, блок «почему мы», цены, FAQ.
2. В `index.html` — токен бота в `const BOT_TOKEN` и `CHAT_ID`.
3. Цвета — в начале `index.html` (`:root`).

Форма отправляет заявку прямо в Telegram-бот. Данные никуда не уходят — только боту клиента.

Деплой: загрузить папку на любой бесплатный хостинг (GitHub Pages, Netlify, Vercel) или отдать архивом.
