# Бот-автоответчик для заявок

Работает на твоём токене напрямую, без внешних сервисов. Отвечает на частые вопросы, копит заявки в CSV и пересылает их тебе.

## Запуск

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=твой_токен
export ADMIN_ID=твой_chat_id
export LEADS_CSV=leads.csv
python bot.py
```

`ADMIN_ID` — это твой numeric chat id. Узнать: напиши боту `/start`, затем открой
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":123456789}`.

## Команды

- `/start` — приветствие
- `/price` — цены
- `/demo` — ссылки на демо и код
- `/lead` — заявка в три шага (имя → контакт)

## Что отвечает сам

| Ключ | Срабатывает на |
|---|---|
| цена | «сколько стоит», «прайс», «price» |
| демо | «пример», «демо», «код», «demo» |
| сроки | «сколько дней», «когда сделаете», «deadline» |
| оплата | «предоплата», «как платить», «payment» |
| стек | «на чём написано», «стек», «stack» |

Всё остальное — нестандартное — считается возможной заявкой: бот уточняет детали и пересылает тебе.

## Важно про вебхук

Если бот создан через сторонний конструктор (например, конструктор ботов), у него стоит чужой вебхук, и `getUpdates` не работает: HTTP 409. Тогда:

```bash
curl -X POST "https://api.telegram.org/bot<ТОКЕН>/deleteWebhook"
```

После этого бот полностью твой и polling работает. Если конструктор тебе больше не нужен — так и оставь.

## Логи

Всё, что бот не распознал, пишется в лог с id отправителя — это твоя заготовка для будущих шаблонов.
