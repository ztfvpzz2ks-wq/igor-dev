# Демо: Telegram-бот приёма заявок

Бот спрашивает имя и контакт, сохраняет заявку в CSV и умеет показать последние заявки.

## Установка

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=123456:ABC-your-token
export LEADS_CSV=leads.csv
python bot.py
```

Токен бота получить у @BotFather.

## Команды

- `/start` — приветствие и короткая инструкция
- `/lead` — пройти опрос (имя, контакт, комментарий)
- `/list` — последние 10 заявок (для проверки)

## Как это выглядит у клиента

Клиент пишет боту, отвечает на три вопроса, и заявка падает в `leads.csv`. Дальше — Google Sheets, CRM или просто Excel.

## Файлы

- `bot.py` — весь код бота
- `requirements.txt` — зависимости
- `leads.csv` — база заявок (создаётся автоматически)
