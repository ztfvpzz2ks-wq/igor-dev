## Демо в этом репозитории

### 1. `demo/telegram_form_bot/` — бот приёма заявок
Бот спрашивает имя и контакт, и складывает заявки в CSV-файл. Тот самый сценарий, за который платят чаще всего: заявка с сайта или из чата попадает клиенту в таблицу.

Запуск:
```bash
cd demo/telegram_form_bot
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=123456:ABC-your-token
export LEADS_CSV=leads.csv
python bot.py
```

Команды бота: `/start` — начало, `/lead` — оставить заявку, `/list` — показать последние заявки.

### 2. `demo/landing_template/` — шаблон лендинга
Одностраничник: чистый HTML/CSS, без внешних CDN, адаптив под телефон, форма отправляет заявку прямо в Telegram-бот. Открывается двойным кликом, деплой — на любой бесплатный хостинг.

### 3. `demo/leads_table/` — приём заявок в таблицу
Скрипт, который принимает заявку с лендинга (POST с JSON) и складывает её в CSV + уведомляет в Telegram. Связка «лендинг -> бот -> таблица» целиком.
