## 6. Portfolio — три проекта

### Проект 1

- **Title:** `Telegram lead bot with admin panel (live demo)`
- **URL:** `https://igor-dev-demo-dgu5m087.agent.mira.tg`
- **Description:**
```
A working demo you can use right now in your browser — no install, no signup.

A client writes to the Telegram bot in free form ("нужен лендинг, @contact").
The bot works out what the request is about, pulls the contact out of the text,
files it and notifies the owner. On the other side there is a small web admin
panel: list, search, filter by status and service, change status inline,
export to CSV.

The bot and the panel share one JSON file — that is the whole data layer.
Pure Python standard library, no dependencies, no database server to pay for.
Handles Ukrainian and Russian input, including і, ї, є, ґ.

The real project ships as source code with a README and a run script.
```

### Проект 2

- **Title:** `Crypto price parser with Telegram alerts`
- **URL:** `https://github.com/ztfvpzz2ks-wq/igor-dev/tree/main/case4_price_parser`
- **Description:**
```
Watches a price across seven exchanges — Coinbase, Kraken, CoinGecko, Gemini,
Gate.io, OKX, Bitfinex — and sends you a Telegram alert when the move passes
your threshold.

The hard part of every exchange is that the price sits at a different depth of
the JSON. That is already solved and documented. Your own threshold, your own
source, your own polling interval. State survives a restart, and a supervisor
script brings it back if the process dies.

It sends messages only, so it can run on the same bot token as another bot
without a getUpdates conflict. Any JSON source works, not just crypto — I add
the source adapter.
```
